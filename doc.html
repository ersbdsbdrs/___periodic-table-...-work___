Документация проекта: Периодическая таблица

1. Обзор

Приложение «Периодическая таблица» — это полноценное веб-приложение, созданное для изучения химических элементов, прохождения интерактивных квизов и получения ежедневных фактов о химии.

Приложение использует легкий бэкенд на Python (Flask), который взаимодействует с публичным API, и кастомный фронтенд на чистом JavaScript, который обрабатывает данные, управляет состоянием и выполняет локализацию на русский язык в реальном времени.

2. Архитектура и стек технологий

  • Бэкенд: Python 3, Flask, Requests
  • Фронтенд: HTML5, CSS3 (тёмная тема), Vanilla JavaScript (ES6+)
  • Внешний API: https://api.periodictableofelements.org

Структура проекта

3. Бэкенд (Flask)

Бэкенд выступает в роли прокси-слоя. Он запрашивает сырые данные из внешнего API, обрабатывает таймауты и отдает данные на фронтенд через чистые REST-эндпоинты.

Эндпоинты (API)

  • GET / — Рендерит основной HTML-интерфейс.
  • GET /api/elements — Запрашивает полный список элементов из внешнего API.
  • GET /api/quiz — Запрашивает случайный вопрос для квиза.
  • GET /api/daily — Запрашивает «Элемент дня».
  • GET /api/element/<int:number> — Ищет элемент по атомному номеру в полном списке и возвращает его данные.

Обработка ошибок

  • Запросы к внешнему API обернуты в блок try/except (с использованием raise_for_status и таймаутом в 10 секунд) для корректной обработки сетевых сбоев.
  • Если элемент не найден, API возвращает статус 404 и JSON {'error': 'не найден'}.

4. Функционал и логика фронтенда

Слой локализации (RU)

Внешний API отдает данные только на английском. Фронтенд использует кастомные словари (categoryRU, elementRU, cluesRU) и регулярные выражения (translateText, translateClue) для перевода названий элементов, категорий и подсказок в квизе на русский язык.

Функция 1: Квест (Викторина)

  • Динамический рендеринг: Запрашивает случайный вопрос. Если вопрос «Какой это элемент?», подсказки форматируются в виде маркированного списка.
  • Ответ по индексу: Вместо ввода полного названия элемента пользователь вводит цифру (1–4). JS сопоставляет индекс с доступными вариантами ответа.
  • Умная проверка: Система анализирует поле quiz.answer и сверяет его с выбранным вариантом по atomic_number, symbol, name, label или value, чтобы обеспечить точность независимо от формата API.
  • Следующий вопрос: Включает кнопку «Ещё вопрос» для генерации нового квиза без возврата в главное меню.

Функция 2: Элемент дня

  • Двойной запрос: Сначала запрашивает дневной элемент для получения его атомного номера, а затем сразу запрашивает полное досье через /api/element/<number>.
  • Детальный вывод: Отображает отформатированный текстовый блок, включая атомную массу, категорию, состояние при комнатной температуре, плотность, температуры плавления/кипения, электронную конфигурацию и год открытия.

Функция 3: Поиск по номеру

  • Поиск по индексу: Позволяет пользователю ввести атомный номер для получения данных конкретного элемента.
  • Форматированное досье: Использует ту же логику перевода и форматирования, что и «Элемент дня», обеспечивая единообразие интерфейса.

5. Установка и запуск

1. Клонируйте репозиторий и перейдите в папку с проектом.

2. Создайте виртуальное окружение:

python -m venv .venv

3. Активируйте окружение:

Для Windows (CMD или PowerShell):

.venv\Scripts\activate

Для Mac/Linux:

source .venv/bin/activate

4. Установите зависимости:

pip install -r requirements.txt

5. Запустите приложение:

python app.py

6. Откройте в браузере: Перейдите по адресу http://127.0.0.1:5000/

6. Планы по улучшению

  • UI-сетка: Реализовать реальную визуальную сетку периодической таблицы вместо кнопочного меню.
  • Кэширование: Внедрить Flask-Caching для сокращения количества запросов к внешнему API (особенно для /elements/).
  • Поиск по имени: Расширить функцию поиска, добавив возможность искать по символу или названию элемента, а не только по атомному номеру.
